# Archived planning documents

These documents were written before and during the first build to plan scope, contracts, and possible research directions. They are kept for history and context. Many describe capabilities that were never built or were built differently, so they do **not** describe the current system.

For the current system, see the [design](../design.md), [results](../results.md), and the [README roadmap](../../README.md#roadmap).
